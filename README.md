# Steampunk Pomodoro

A productivity timer that combines the Pomodoro Technique with a distinctive steampunk aesthetic. This project creates an immersive focus environment using mechanical visuals, making time management a bit more engaging.

## Features

- **Customizable Timer**: Set your own focus, short break, and long break durations.
- **Atmospheric Design**: Visuals inspired by brass gears, steam gauges, and Victorian machinery.
- **Responsive Layout**: Works seamlessly on desktop and mobile devices.

## Tech Stack

Built with modern web technologies:
- **[React](https://react.dev/)**: For component-based UI architecture.
- **[Vite](https://vitejs.dev/)**: For fast development and optimized production builds.
- **[Tailwind CSS](https://tailwindcss.com/)**: For utility-first styling and theming.

## Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Tristan578/steampunk-pomodoro.git
    cd steampunk-pomodoro
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  Open your browser to the local URL provided in the terminal (usually `http://localhost:5173`).
